# 北京大学集成电路学院夏令营

## 基本信息
北京大学集成电路学院（以下简称“北集”）作为顶尖学府的热门学院，其夏令营的竞争非常激烈。

需要明确的是，硕士和博士的选拔逻辑有显著差异：
1. **硕士生**：采取**强com（委员会制）**模式。门槛极高，人数极少，10人左右，22和23级南苏集电无人入营。
2. **直博生**：采取**弱com（导师制）**模式。直博入营名额多但需要提前联系老师，能否入营基本取决于老师意愿，但具体录取还是由导师决定。

## 考核环节
### 1. 硕士考核
硕士生的考核流程因为没人入营所以了解不多，这里提供南大电子同学给的信息：
- **时间**：不少于20分钟。
- **面试**：全方位考察。包含英文自我介绍与问答，专业课题目现场抽取回答，项目提问等等。

### 2. 直博考核
直博生的考核：
- **综合面试**：全方位考察。包含英文自我介绍与问答（注意，北集分为4个方向，每个方向英语考核方式不一，这里是集成电路设计方向的考核）、专业课现场抽题问答、项目提问等，时间30分钟。
- **具体流程**：笔者联系的老师作为评委之一（总共5位），先进行英文自我介绍，随后英文提问关于家乡（可以提前准备常见英文问题），然后是中文讲解自我陈述PPT（不超过5分钟），PPT陈述后进行专业课题目抽取，从所报名方向的题目中选择2类题目，各抽取1道题作答，共2题。如对抽取题目不熟悉，允许再抽取一次。例如：报名集成微纳电子方向的学生，可以在“半导体物理，半导体器件，集成电路工艺”中选择其中两个模块的题目作答，以下为各方向的题目范围：集成微纳系统（普通物理、半导体物理、电子线路）；集成电路设计（模拟集成电路、数字集成电路、数字与模拟电路）；集成微纳电子（半导体物理，半导体器件，集成电路工艺）；电子设计自动化与计算系统（半导体物理，集成电路基础，算法与编程，微处理器设计）。北集专业课题目较为灵活，且对课程内容理解和南大集电有很大不同。老师很可能针对抽取的问题进行进一步深入考核基础知识，也可能问项目，较为随机。
